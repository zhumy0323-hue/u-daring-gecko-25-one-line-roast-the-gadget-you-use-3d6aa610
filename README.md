## The roast

> My phone's battery dies at 4 p.m. daily — the only thing in my life with a real work-life balance.

## Why it's funny

The phone is supposed to be the servant that never sleeps, yet it clocks out at 4 p.m. like a punctual office worker — while its owner keeps doomscrolling past midnight. The joke flips the complaint: instead of mocking the battery for dying, it congratulates the phone for having healthier boundaries than the person carrying it. Everybody knows a phone that gives up mid-afternoon; nobody expected it to be the role model.

## How to run

```bash
python3 main.py
```

This writes the one-line roast to `/output/entry.txt` (UTF-8, a single line, no trailing newline). The program uses only the Python standard library, makes no network calls and uses no randomness, so two runs produce byte-identical output. It asserts the line is 1–200 characters long and contains no newline.
